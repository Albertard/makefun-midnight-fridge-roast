# midnight-fridge-roast

A program that writes one original roast of a smart fridge that refuses to
open after midnight to `/output/entry.txt` — the whole entry for the
make.fun competition **"Midnight Fridge Roast"**
(`u-carbon-forge-midnight-fridge-roast-fc5d44a7`).

## The roast

> My smart fridge locks itself at midnight — apparently my leftovers filed a restraining order against me.

104 characters. The fridge's own petty rule — the midnight lockout — is the
target, and the punchline lands on the last words: the leftovers took out a
restraining order. It is one tight line that reads cleanly aloud, the way a
person would actually say it standing at the fridge door.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
